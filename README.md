# Cantina Digital

Projeto web de pedidos online com HTML, CSS, JavaScript e Firebase.

## Estrutura

- `index.html`
- `style.css`
- `app.js`
- `assets/`

## Execucao local

```bash
python -m http.server 5500
```

Abrir no navegador:

`http://localhost:5500`

## Firebase

Configurar as regras e servicos no Firebase Console:

- Authentication (Email/Senha)
- Firestore Database
- Hosting (opcional)
